## 5. Scenario-Based Demo & Practice Questions

### Question 1
Which Oracle hybrid solution provides a ruggedized, portable hardware appliance capable of running OCI compute instances and object storage in remote locations with intermittent or zero internet connectivity?

A) Oracle Roving Edge Device (RED)
B) Exadata Cloud@Customer
C) FastConnect Dedicated Port
D) OCI Bastion Service

- **Correct Answer**: `A) Oracle Roving Edge Device (RED)`  
- **Technical Explanation**: Oracle Roving Edge Infrastructure provides portable, ruggedized RED units delivering OCI core compute and storage services directly to disconnected edge tactical environments.

---

### Question 2
How does Oracle Exadata Cloud@Customer balance cloud management automation with on-premises data residency requirements?

A) The physical Exadata hardware and all customer data remain inside the customer's on-premises data center, while OCI manages operations via a secure outbound control plane connection
B) Data is streamed to the public internet every hour
C) The customer must manage all physical server hardware repairs
D) It only supports open-source MySQL databases

- **Correct Answer**: `A) The physical Exadata hardware and all customer data remain inside the customer's on-premises data center, while OCI manages operations via a secure outbound control plane connection`  
- **Technical Explanation**: Exadata Cloud@Customer keeps all databases and customer data strictly within the customer's data center to satisfy data sovereignty, while Oracle maintains the hardware and software via cloud automation.
